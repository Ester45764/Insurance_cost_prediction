# Overview

This project uses Machine Learning to predict medical insurance charges based on personal characteristics such as age, BMI, smoking status, sex, number of children, and region.

The main goal is to understand and apply regression techniques, perform Exploratory Data Analysis (EDA), and compare model performance using different feature combinations.
Dataset

The dataset contains information about individuals and their medical insurance charges.

Features:

* `age`: Age of the individual.

* `sex`: Sex of the individual.

* `bmi`: Body Mass Index.

* `children`: Number of children covered by the insurance.

* `smoker`: Smoking status.

* `region`: Residential region.

*`charges`: Medical insurance charges (target variable).

#Project Workflow

## Data Preprocessing

Inspect and clean the dataset.

Encode categorical variables.

Prepare the features and target variable.

Exploratory Data Analysis (EDA)

Analyze feature distributions.

Study relationships between features and insurance charges.

Explore categorical variables and their proportions.

Use visualizations to identify patterns.

##Model Training

Split the dataset into training and testing sets.

Train regression models using different feature combinations.

Generate predictions on unseen test data.

#Model Evaluation

*Compare model performance using:

*Mean Absolute Error (MAE)

*Root Mean Squared Error (RMSE)

*Coefficient of Determination (R²)
