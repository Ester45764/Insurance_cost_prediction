# Overview

This project uses Machine Learning to predict medical insurance charges based on personal characteristics such as age, BMI, smoking status, sex, number of children, and region.

The main goal is to understand and apply regression techniques, perform Exploratory Data Analysis (EDA), and compare model performance using different feature combinations.
